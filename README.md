# Rust Test Applications

This repository contains various Rust applications designed to test and demonstrate 
specific functionalities. Each sub-folder represents a distinct application and
includes its own `README.md` with details on its purpose, usage, and implementation.

## Objective

The goal of this repository is to provide a collection of Rust-based tools that
explore different system functionalities, including process manipulation, privilege
enumeration, and DLL execution. These applications serve as test cases for research
and development purposes.

## Structure

Each sub-folder contains a standalone Rust application.

Every application is documented with its own `README.md` detailing its function and usage.

## Disclaimer

These applications are intended for research, educational, and testing purposes only.
Use them responsibly and ensure compliance with legal and ethical guidelines.
